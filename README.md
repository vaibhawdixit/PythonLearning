This repository contains Python scripts for two fundamental programming tasks: calculating factorials and performing mathematical operations using the math module.
Task 1: Factorial Calculator
  This program defines a function factorial(n) that calculates the factorial of a given number using a loop.
  Input: A sample integer (e.g., 5).
  Process: Iterates from 1 to n to find the product.
  Output: Returns the calculated factorial value.
Task 2: Math Module Operations
  This script demonstrates the use of Python's built-in math module to perform advanced calculations based on user input.
  Features:
  1)Calculates the Square Root.
  2)Calculates the Natural Logarithm (base e).
  3)Calculates the Sine of the number (in radians).
Input: Prompts the user to enter a numeric value.
